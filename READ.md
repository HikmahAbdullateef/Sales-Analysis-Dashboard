\# Sales Analysis Dashboard



\## Overview

This project is a Sales Analysis Dashboard built using Excel and Power BI to analyze business performance, customer trends, revenue growth, and profitability. It provides interactive visual insights that help stakeholders make data-driven decisions.



\## Tools Used

* Power BI
* Data Modeling
* DAX Measures
* Data Visualization
* Data Cleaning and Transformation



\## KPIs Included

The dashboard tracks key business metrics including:



* Total Revenue: 307.09M
* Profit: 126.29M
* Total Sales: 60K
* Total COGS: 180.80M



\## Insights

* The United States has the highest customer count.
* Revenue increased steadily between 2005 and 2008.
* Monthly Sales experienced fluctuations during the year.
* Certain customers contribute significantly more profit than others.



\## Interactive Filters

Users can filter data by:

* Gender
* Occupation
* Education Level
